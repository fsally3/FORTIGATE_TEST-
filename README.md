FortiGate Firewall Address Objects – Terraform (Research Phase)
Overview

This repository is part of ongoing research and development into managing FortiGate firewall address objects using Terraform.

The current configuration establishes the foundational layout required to create and manage firewall address objects in a structured, version-controlled manner.

Current Focus

Defining Terraform provider configuration

Building firewall address object resource structure

Parameterising attributes for reusable configuration

Establishing a clean repository layout

Status

Research and build phase.
No Terraform execution or firewall changes have been applied at this stage.

Further development and controlled implementation will follow.
